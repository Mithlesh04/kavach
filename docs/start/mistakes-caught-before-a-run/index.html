Mistakes Caught Before a Run

Also known as: bugs common mistakes typo off by one null index out of range divide by zero static analysis linter compile time safety catch errors early

● Beginner6 minBefore this: Classic Mistakes, Fixed

Everyday mistakes, each one a small program, and the step that catches it before the program runs, with the message it gives.

In simple terms

Everyone makes small slips, like a misspelled name or a missing case. Kavach works like a spell checker for programs: it catches many of these before the program runs, and its message says what went wrong.

A mistake found while you type costs seconds. The same mistake found by a customer costs much more. These are the mistakes people make under deadline pressure: a misspelled name, a wrong type, a missing case, an index one past the end. Each was checked with kavach check when this site was built.
