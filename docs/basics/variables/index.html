Variables

Also known as: variable constant const let var declare assignment type inference integer float boolean string interpolation format immutable mutable

● Beginner4 minBefore this: OutputSpec 1.4

A variable is a name for a value. const names one that never changes; let names one that can.

In simple terms

A variable is like a labelled jar: the label is the name, and what is inside is the value. Some jars are sealed (const), and some you can open and refill (let).

A whole program

You don't have to write a type: 31 makes age an Int, and "asha" makes name a String. Write one when you want to say it, as in price: Float.

Use const unless the value really must change. Then a reader knows at a glance which names can move.

Names that start with _

A variable nobody reads gets a warning, so leftovers don't pile up. Start the name with _ to say it is unused on purpose, and the warning goes. _ on its own throws a value away: an item you skip, or a loop counter you don't need.
