Tensors: Making tensors

Also known as: arange linspace zeros ones full eye identity random normal randn randint random_int astype convert

● Intermediate5 minBefore this: Tensors

tensor.of, of_rows, zeros, ones, full and eye make a tensor from numbers; arange and linspace count; random and normal draw, the same under one seed on every machine.

In simple terms

To start working with a grid of numbers you either write the numbers out, fill a shape with one number, or count along a line. Random ones come from the same generator as the rest of Kavach, so a seed gives the same numbers every time.

  • zeros, ones and eye name the number type, as nothing else says it; full, of and of_rows take it from their numbers.
  • A shape's sizes are 0 or more. [] is a shape too: one number and no dimensions.
  • of_rows needs every row as long; rows of different lengths are a panic naming both lengths.

Counting

  • arange counts as start..end does: end is left out. Each number is worked out as start + i * step, so no rounding builds up. A step of 0 is a panic.
  • linspace gives count numbers with both ends included, and the last is exactly end.

Random numbers

random, normal and random_int draw through std.random, in order. So random.seeded(s) { … } gives the same tensor on every machine, and under kavach test the Random fake gives repeatable ones:

random_int draws each number exactly as random.int draws it, so under one seed a tensor of 10 gives the same numbers as 10 calls of random.int:

One call draws at most 16,777,216 (224) numbers, a 4,096 × 4,096 matrix. Asking for more breaks the function's contract:

The bound lets the tests kavach test makes from that contract end in time: they skip shapes it rules out.

They need uses Random, as every random number does. normal uses the Box–Muller method, with std.math's functions, which give the same bits everywhere.
