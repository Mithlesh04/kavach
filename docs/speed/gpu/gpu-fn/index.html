GPU: gpu fn

● Advanced4 min

A gpu fn uses only what a GPU can do: 32-bit numbers and Bool, arithmetic, if, loops and other gpu fns. Anything else is a compile error that names it.

In simple terms

A GPU's many helpers work only with plain numbers, like a room of people with calculators, cut off from the outside world. A gpu fn may use only what they can do, and Kavach checks this before the program runs.

AllowedNot allowedWhy
Float32, Int32, UInt32, BoolFloat, Int and other 64-bit typesGPUs compute 32-bit numbers fast: consumer NVIDIA GPUs run 64-bit floats at 1/64 of the speed, and WebGPU's shading language has none
those types, and records and tuples of 1 to 8 of them, as parameters and resulttext, lists, maps, pointerseach GPU thread holds a few fixed-size numbers; it can't make or grow a value in memory
const, let, =, if/else, while, for over 0..n, returnfor over a list, match, try, recursiona GPU has no call stack, and nothing a thread could loop over but its own numbers
+ - * / % and comparisons; ** on Float32print, debug, capabilities (files, network, AI)thousands of threads run at once, cut off from the outside world
Float32(n), Int32(x); abs, min, max, clamp; math.sqrt, floor, ceil, round, powa function that isn't a gpu fn, other std modulesthe compiler can only translate what it has checked follows these rules
