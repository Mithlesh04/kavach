Settings

Also known as: settings configuration config kavach.toml toml options defaults environment variables env vars dotenv KAVACH_GPU ANTHROPIC_API_KEY NO_COLOR log level

● Intermediate6 minBefore this: Project LayoutSpec 10.11

Every setting a project can have, with its values and its default: kavach.toml, then environment variables.

In simple terms

kavach.toml is like a form with boxes for your project's choices. Leave a box empty and the usual choice is used; write in a box that doesn't exist, and Kavach tells you, so a typo is never missed.

A project's settings live in kavach.toml, next to src/. Leave a setting out and its default applies:

A key or section that isn't in the tables below is an error, and the message lists the names the section does have, so a typo can't be ignored silently:
