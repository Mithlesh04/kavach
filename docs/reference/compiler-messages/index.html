Compiler Messages

● Intermediate10 minSpec 13.6

The compiler's errors and warnings, and the panics of a running program, as the samples on this site show them: each with the page that explains it.

Each line below was printed by the real compiler, or by a program it built, when this site was built: the samples' output is checked on every build. A message says what is wrong and, most of the time, what to write instead. The compiler has more messages than the samples show.
