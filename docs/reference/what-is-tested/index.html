What Is Tested

Also known as: tests tested conformance test suite coverage what is checked verified rules spec proof refused compile error panic works

● Intermediate3 min

Every rule the conformance tests check, by spec chapter: what works, and what wrong use is refused.

A conformance test is a small program that checks one rule of the spec. Its first lines say which rule, which section, and what must happen: an output, a compile error, a panic. The test runner checks every one, so each rule listed here holds for the compiler this site was built with.

  • Works: the program runs and prints what the test expects.
  • Refused: wrong use is stopped, by a compile error, a warning, a panic, an exit code other than 0, a failing test, or an error value the program prints (// Checks: misuse).
