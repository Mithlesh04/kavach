What http.serve allows each client (spec 14.11), so a slow or hostile one can't hold the server: every limit has a safe default.

pub type ServeLimits {
    /// The most a request's line and headers may take: 431 past it.
    pub max_header_bytes: Int = 16_384
    /// The most a request's body may take: 413 past it, refused by its
    /// `content-length` before it is read.
    pub max_body_bytes: Int = 10_000_000
    /// How long a request's line and headers may take to come: 408 past
    /// it (a client sending them a byte at a time can't hold a task).
    pub header_timeout: Duration = 10.seconds
    /// The slowest a body may come, in bytes a second, after a second's
    /// grace: 408 when slower.
    pub min_body_rate: Int = 1_000
    /// How long a kept-open connection may wait for its next request.
    pub idle_timeout: Duration = 5.seconds
    /// The most connections at once: past it, 503 with `retry-after`.
    pub max_connections: Int = 10_000
    /// The most requests being answered at once: past it, 503.
    pub max_in_flight: Int = 1_000
    /// The largest request body read whole into `r.body`; a larger one is
    /// read by the handler with `r.read_body()`.
    pub buffered_body: Int = 1_000_000
    /// What `retry-after` says on a 503, in seconds.
    pub retry_after: Int = 1
    /// On a stop signal, how long to finish the requests under way
    /// (spec 5.8): `http.serve` holds the program's stop that long.
    pub drain_timeout: Duration = 10.seconds
}
