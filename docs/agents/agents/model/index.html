Agents: model

● Intermediate3 minBefore this: Agents: Declaring an agent, ask<T>

model names the AI model, and its settings, for every ask in the agent's handlers.

In simple terms

An agent that asks an AI needs to know which one to ask. model says it once, at the top of the agent, the way a company names one supplier for all its orders instead of choosing again for each one.

Two agents share careful(), and a third has no model. The audit log names the model each ask used. This was a dry run, so no model was called and nothing cost:

  • model takes a Model value: the model's name, and the settings in the table below.
  • A function with no parameters makes a group. Reviewer and Auditor both call careful(), so changing that one function changes both.
  • Greeter has no model, so its ask uses the default, claude-haiku-5-5.
  • The model is worked out when the program is built, so you can always read which model an agent uses.

What a Model takes

SettingTypeDefaultRangeWhat it does
nameStringrequiredA model the provider serves: claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5 and othersWhich model answers, by the provider's name for it. Bigger models usually cost more per token; smaller ones are usually quicker and cheaper.
effortEffortthe model's ownEffort.Low, Effort.Medium, Effort.High, Effort.XHigh, Effort.MaxHow hard the model works on an answer: more effort, better answers and more tokens. The provider's main control of quality against cost.
max_tokensInt4,0961 to 128,000, checked when builtThe longest answer allowed, thinking included. An answer cut off at this length fails with Failed, without asking again.
thinkingBoolthe model's owntrue or false. false is refused when built for claude-opus-5-5, which always thinks, and with effort above Highfalse asks the model to answer straight away, without thinking first: far fewer output tokens, but it can get some answers wrong. See Choosing the model for what it measured.
instructionsStringnot sentAny textStanding instructions the model gets with every ask, such as who it works for and how to answer: a system prompt.
stop[String]not sentA list of textsThe answer ends where the model writes one of these texts.
timeoutDuration120 secondsA Duration, such as 60.secondsHow long one try may take. A try that takes longer is sent again, like a busy one.
retriesInt40 to 10, checked when builtHow many times a busy, dropped or late call is sent again, after waits of 1, 2, 4 and 8 seconds, then 8 again, each a random time between half and all of that. Then the ask fails with Failed.
api_urlStringKAVACH_AI_URL, or Anthropic's addressThe address of a service that speaks Anthropic's Messages API: another account, a proxy, a gatewayWhere this model's calls go, instead of Anthropic's own address.
api_key_envString"ANTHROPIC_API_KEY"The name of an environment variableWhich environment variable holds the key for this model, so two models can use two accounts. The key itself never goes in the code.
extraStringnot sentThe text of a JSON object, checked when builtMore request fields, added as they are, for a provider setting Kavach doesn't name yet. A field here replaces one Kavach would send.

A value marked "checked when built" is refused by the compiler, with a message. Everything else goes to the provider as it is, and a value the provider refuses fails the call with Failed and the provider's message. The ranges follow Anthropic's Messages API reference.
