Model type

Which model an ask uses, and with what settings (spec 8.4, decisions 0056 and 0059): an agent's model, or a call's model:, alone or in a list of models tried in turn (spec 8.4, *Fallbacks*).

pub type Model {
    /// the provider's name for the model, such as "claude-haiku-5-5"
    pub name: String
    /// none: the model's own; how hard it works on an answer, from `Low`
    /// to `Max`: more effort, better answers and more tokens
    pub effort?: Effort
    /// none: 4,096; the most tokens an answer may take, thinking included,
    /// from 1 to 128,000
    pub max_tokens?: Int
    /// none: the model's own; false: answer without thinking first, for
    /// fewer output tokens (spec 8.4)
    pub thinking?: Bool
    /// none: none; standing instructions sent with every `ask` (a system
    /// prompt)
    pub instructions?: String
    /// none: none; text that ends the answer where the model writes it
    pub stop?: [String]
    /// none: 120 seconds; how long one try may take before it is sent again
    pub timeout?: Duration
    /// none: 4; how many times a busy, dropped or late call is sent again,
    /// from 0 to 10
    pub retries?: Int
    /// none: `KAVACH_AI_URL`, or the provider's address; where the calls go
    pub api_url?: String
    /// none: the provider's, "ANTHROPIC_API_KEY" for Anthropic; the
    /// environment variable holding the key
    pub api_key_env?: String
    /// none: none; more request fields, as the text of a JSON object
    pub extra?: String
    /// none: `Anthropic()`; whose API the model is reached through
    pub provider?: Provider
}

UnderWay type

Provider interface

How ask talks to one AI provider (spec 8.4, decision 0140). It only translates; the runtime reads the key, sends, retries and keeps the limits, so provider code never holds the key.

pub interface Provider {
    /// The settings of `model` this provider can't take, each with why:
    /// compile errors, as the compiler runs it when it builds the program.
    fn check(self, model: Model) -> [String]
    /// The variable holding the key when the `Model` names none.
    fn key_variable(self) -> String
    /// Where the key goes in a request; the runtime puts it there.
    fn auth(self, model: Model) -> Auth
    /// The request for one `ask`.
    fn request(self, call: AskCall) -> HttpCall
    /// What came back: an answer, or why there is none.
    fn read(self, call: AskCall, reply: HttpReply) -> Reply
    /// The price of a model's tokens; none: not known. Worked out when
    /// the program is built, as `check` is (spec 8.4, *Prices*).
    fn price(self, model: String) -> Price?
    /// The request that counts a call's input tokens; none: the provider
    /// has no counting call (`ai.count`, spec 8.4).
    fn count_request(self, call: AskCall) -> HttpCall?
    /// The count in that request's reply; none: the reply has none, and
    /// `read` says why.
    fn read_count(self, call: AskCall, reply: HttpReply) -> Int?
    /// A count made without the network; none: no way to make one.
    fn estimate(self, call: AskCall) -> Estimate?
}
