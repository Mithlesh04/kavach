What the spec lists

CallGives
table.of(rows) -> Table<R>A table of the list rows
table.read_csv<R>(path) -> Table<R> ! CsvErrorThe rows of the CSV file at path, read as the file is read, so the file's text is never held whole
table.parse_csv<R>(text) -> Table<R> ! CsvErrorThe same, from text, such as the body of a web response
t.write_csv(path) ! CsvErrorWrites the table as CSV, atomically, as fs.write_text does (14.3)
t.to_csv() -> StringThe table as CSV text
MethodGives
t.len()How many rows it has
t.columns() -> [String]The names of its columns, in order
t[i]Row i, as an R; out of range is a panic, as for a list (2.2)
t.get(i)Row i, or none
t[a:b:step]A table of those rows, as a list is sliced (2.19): t[0:10], t[#5:], t[::2]
t["name"]The column name, as a list: sales["amount"] is a [Float]
t.rows() -> [R]Every row, as a list

Where a list's method gives a list of records, a table's gives a table:

MethodGives, on a table
t.filter(test), t.sort_by(key), t.unique(), t.unique_by(key)A Table<R>
t.map(f)A Table<S> when f gives a record S whose fields a cell can hold; otherwise a list, as on a list
t.group_by(key)A {K: Table<R>}
t.inner_join(other, key, other_key, row), t.left_join(…)A Table<S> of the records row makes; other is a table or a list
t.describe()With no lambda: a {String: Summary}, the summary (14.2) of each number column, in column order. An optional column is left out, as nothing is skipped without saying (for a maintainer's review)

What is tested

Each conformance test in tests/conformance/ checks one rule of spec 14.34. 25 tests: 19 check that it works, 6 that wrong use is refused.

RuleSpecChecksTest
a field with no CSV column takes its default, or none if it is optional; otherwise reading fails with Missing.14.34workscsv-a-missing-column-takes-its-default
a quote left open, or a line with more or fewer cells than the first, fails reading a CSV with Syntax.14.34refused: error valuecsv-a-quote-left-open-is-a-syntax-error
a quoted CSV cell may hold line breaks; lines may end with \n or \r\n, and a byte order mark at the start is skipped.14.34workscsv-a-quoted-cell-may-hold-a-line-break
an empty CSV cell is none for an optional field, "" for a String, and the default for a field with one; anywhere else it fails with Value.14.34workscsv-an-empty-cell-is-none-or-empty-text
a CSV column with no field fails with Unknown, unless unknown: CsvUnknown.Ignore is given.14.34refused: error valuecsv-an-unknown-column-is-refused
a CSV cell is read strictly, as Int(s) and Float(s) read text: a cell that doesn't fit fails with Value, naming its line and column.14.34refused: error valuecsv-cells-are-read-strictly
each CSV column name matches a field exactly, and the columns may come in any order.14.34workscsv-columns-come-in-any-order
CSV is read by RFC 4180: the first line names the columns, a quoted cell may hold the separator and "" for a quote, and an empty cell is none for an optional field.14.34workscsv-reads-a-header-and-quoted-cells
a CSV cell of a category is its variant's name, and a Date is read as ISO 8601 writes it; anything else fails with Value.14.34workscsv-reads-categories-and-dates
write_csv writes a table to a file and read_csv reads it back, the file read line by line; both need the Fs capability.14.34workscsv-round-trips-through-a-file
each CSV row is checked against its type's invariants; a row that breaks one fails with Value, its found the row when no one column broke it.14.34refused: error valuecsv-rows-are-checked-against-invariants
sep: is the character between CSV cells, ',' unless given; reading and writing take it.14.34workscsv-tabs-separate-with-sep
writing CSV gives a line of column names, then a line for each row; a cell is quoted only when it holds the separator, a quote or a line break, and none is an empty cell.14.34workscsv-written-cells-are-quoted-only-when-needed
t["name"] is the column name as a list of its field's type.14.34workstable-a-column-is-a-typed-list
t["name"] with a name that is not a field of the row type is a compile error that names the fields there are.14.34refused: compile errortable-a-misspelled-column-is-a-compile-error
t.describe() with no lambda gives the summary of each number column, by its name, in column order.14.34workstable-describe-summarizes-each-number-column
a table has the methods of a list of records, with the same results; where a list's gives a list of records, a table's gives a table.14.34workstable-has-the-methods-of-a-list
a table's inner_join and left_join take a table or a list, and give a table of the rows row makes.14.34workstable-joins-take-a-table-or-a-list
JSON goes through std.json: json.stringify(t) writes a table as an array of rows, and table.of(json.decode<[R]>(text)) reads one.14.34workstable-json-is-an-array-of-rows
t.map(f) gives a table when f makes a record whose fields are cells, and a list otherwise.14.34workstable-map-to-rows-gives-a-table
table.of(rows) makes a table of a list of records: len, columns, t[i], t[#k], get and rows read it as a list is read.14.34workstable-of-a-list-has-its-rows
print(t) writes the column names, then the rows, each column as wide as its widest cell, numbers to the right, and then its size.14.34workstable-prints-as-a-grid
a printed table of more than 10 rows shows its first 5 and last 5, with a … line between, then its size.14.34workstable-prints-ten-rows-at-most
