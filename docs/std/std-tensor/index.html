spread function

The numbers items of a tensor of shape s, broadcast to shape out, in order: a size of 1 is used again for every place of the larger size.

pub fn spread<T>(s: [Int], items: [T], out: [Int]) -> [T]
    require count(s) == items.len() and count(out) != none
    require broadcast(s, out) == out and s.len() <= out.len()
    example spread([3], [1, 2, 3], [2, 3]) == [1, 2, 3, 1, 2, 3]
