What is tested

Each conformance test in tests/conformance/ checks one rule of spec 14.25. 19 tests: 10 check that it works, 9 that wrong use is refused.

RuleSpecChecksTest
a new user's name is 1 to 20 ASCII letters, digits, _, - or ., the first a letter or _; add_user with any other name fails with Failed before anything changes.14.25refused: error valuesystem-a-new-user-name-is-plain
Listing the applications installed needs System.critical.read; uses System doesn't cover it.14.25, 8.1refused: compile errorsystem-apps-need-critical-read
system.battery() is none with no battery, or a Battery whose percent is 0 to 100 and whose minutes_left is -1 while charging or not known.14.25workssystem-battery-stays-in-range
Reading the processor's model, maker and speed needs uses System.14.25refused: compile errorsystem-cpu-needs-system
uses System doesn't cover System.critical.read: reading serial numbers, MAC addresses or the applications installed is written by name.14.25refused: compile errorsystem-critical-is-not-covered-by-system
Ending programs, freeing a port, adding or removing users and locking the session need System.critical.write; System.critical.read doesn't cover it.14.25, 8.1refused: compile errorsystem-critical-read-does-not-cover-write
reading the machine's memory, processor, GPUs, hostname or uptime needs uses System.14.25refused: compile errorsystem-details-need-the-capability
Each device's kind is one of the kinds the spec lists, and each display's connection one of the ports it names or "".14.25workssystem-device-kinds-are-the-listed-ones
SystemError is NotFound(what:), Denied(reason:) or Failed(reason:).14.25workssystem-error-is-not-found-denied-or-failed

std.system gives every part of the machine as typed records: volumes, network adapters, devices, drivers, disks, memory modules, displays, sensors, the battery, the board, BIOS and model with System, and the applications and ids with System.critical.read.14.25workssystem-parts-come-typed

std.system lists the programs running, the ports in use with the program holding each, the user this program runs as and every account; ending a program that isn't there fails with NotFound; net.free_port() gives a port nothing listens on.14.25workssystem-programs-ports-and-users
