Kavach tutorial

Benchmarks

41 whole programs, each written in Kavach, C++ and often Python, Go or C#, run on one machine. Kavach is faster than C++ in 31 of 36 of them, and the others are here too.

How these are measured

  • The same algorithm in every language, written the way a fluent programmer would.
  • Whole programs, start to finish, on the same machine; the best of several runs.
  • Every number is read from the benchmark's README, where each run is recorded, never typed into this page.
  • Each suite ends with one command to run it yourself.
  • In a race, every bar fills at the same speed: milliseconds to scale, so the first to finish is the fastest.

The machine

Every suite here ran on one laptop, unless its README says otherwise.
