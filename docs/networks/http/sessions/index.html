HTTP: Sessions

● Intermediate2 min

http.open keeps one connection open for many requests, instead of connecting again for each.

In simple terms

Like staying on one phone call to ask several questions, instead of hanging up and dialling again for each one. Each question waits for its answer before the next.

Requests on a session go one after another, each waiting for its answer. A session is for one task at a time: give each task its own, so no task reads another's answer.
