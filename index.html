What kind of language is Kavach?

Compiled

kavach build turns a program into one native executable. No interpreter or virtual machine runs it.

Quick to try, like a script

A file can be a single print line, and kavach run starts it at once while you learn.

Statically typed

Types are checked before anything runs, and worked out for you: you rarely write them.

No garbage collector

Memory is freed the moment nothing uses it, so there are no pauses.

Built with Rust

The compiler and runtime are written in Rust and compile through LLVM. Much of the standard library is written in Kavach itself.
