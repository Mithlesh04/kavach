# Security

Kavach is a language for safe software, so security reports come first.

## Reporting a problem

[Open an issue on GitHub](https://github.com/Mithlesh04/kavach/issues/new) with:

- what you found
- steps to reproduce it
- the impact you expect

Issues are public. If the details could put people at risk, describe the problem in general terms and ask how to send the rest.

We aim to reply within 3 working days.

## Scope

- The compiler accepting a program that breaks a language guarantee (memory safety, capability checks, contracts, secrets).
- The runtime failing to enforce agent limits, approvals or audit logging.
- Vulnerabilities in the package manager or registry.
